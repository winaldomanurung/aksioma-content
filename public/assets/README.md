Curated SVG asset subset for Aksioma Content Studio.

Lucide icons: original SVGs from https://github.com/lucide-icons/lucide
License: ISC. Full license at public/assets/licenses/lucide-LICENSE.txt.

Phosphor duotone icons: original SVGs from https://github.com/phosphor-icons/core
License: MIT. Full license at public/assets/licenses/phosphor-LICENSE.txt.

Decorative SVGs: original Aksioma compositions inspired by generative
shape aesthetics (not exported from, or affiliated with, Haikei).
These are static local assets. New external imagery must be vetted and
added explicitly to the allowlisted registry before it can be used in Studio.

All icons are loaded from /assets; no runtime CDN dependency.
